# Crash Claim

A 2D pixel-art platform game where you drive a car through a tile-based level, collect coins, avoid falling rocks, and reach the finish.

## How to Play

- Use the **Left** and **Right Arrow** keys to move.
- Press **Space** to jump.
- Collect coins and avoid rocks and falling into the killzone.
- Reach the finish line to complete the level.
- Press **Enter** after a game over or level completion to restart.

## Features

- Tile-based platforming with moving platforms
- Coin collection and pickup sound
- Background music and sound effects
- Falling rock hazards
- Score display, game over, and level completion screens

## Requirements

- Godot **4.7** or later

## Run the Game

1. Download or clone this repository.
2. Open the project in Godot using `project.godot`.
3. Press **F6** to run the main scene, or **F5** to run the project.
